## Run it

```sh
python3 main.py
```

This copies `source.jpg` to `entry.png` (1024×1024 JPEG, 287,587 bytes),
verifies the JPEG magic bytes, the 1 MiB size limit, and the SHA-256
fingerprint. Two runs produce byte-identical output. Standard library
only — no dependencies to install.
